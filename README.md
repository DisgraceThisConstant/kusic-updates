# Kusic 1.2.0

Музыкальный плеер для Windows 10/11 x64: библиотека, поиск и импорт музыки, мини-плеер, настраиваемый виджет рабочего стола и настройки звучания.

**[Скачать Kusic 1.2.0](https://github.com/DisgraceThisConstant/kusic-updates/releases/latest)**

Установщик предлагает обновить найденный Kusic, включая старые клиенты без встроенных обновлений. Коллекция, музыка и настройки сохраняются. Для переносной сборки новая установка подключает прежнюю коллекцию и сохраняет исходную папку.

Текущая стабильная версия — **1.2.0**. Прежние номера 1.3–1.7 были ошибочно присвоены промежуточным сборкам; они перенесены в архив. Для перехода с таких сборок и с прежней сборки 1.2.0 один раз запустите новый установщик вручную. Следующие согласованные стабильные версии будут доступны через **Настройки → Обновления**.

Плеер проверяет стабильные обновления без аккаунта GitHub. Автоматическую загрузку можно отключить; о новой версии сообщит индикатор рядом с настройками. Перед установкой проверяются размер и SHA-256.

Экспериментальные версии, когда они опубликованы, показываются отдельным предложением с описанием изменений и предупреждением о возможных ошибках. Их просмотр можно отключить в настройках. Загрузка и установка запускаются вручную; экспериментальная сборка не заменяет последнюю стабильную версию на GitHub. Сейчас экспериментальных сборок нет.

Содержание, номер и время публикации следующих релизов согласуются с владельцем проекта. Изменение установщика само по себе не повышает версию плеера.

Этот репозиторий содержит готовые установщики, описания релизов, контрольные суммы и файлы обновлений `update.json` и `experimental.json`.
