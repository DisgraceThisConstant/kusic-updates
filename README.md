# Kusic

Музыкальный плеер для Windows 10/11 x64.

Скачайте установщик на [странице релизов](https://github.com/DisgraceThisConstant/kusic-updates/releases/latest). Повторная установка обновляет существующую версию и сохраняет вашу коллекцию, музыку и настройки.

Начиная с 1.2.0, Kusic проверяет новые версии и загружает обновление в фоне. Установка запускается из **Настройки → Обновления**. После установки плеер открывается снова.

Версии 1.1.0 и старше нужно один раз обновить свежим установщиком. Дальнейшие обновления доступны в самом плеере.

Этот репозиторий содержит установщики, историю изменений и публичный файл `update.json`. Для проверки обновлений пользователям не нужен аккаунт GitHub. Контрольные суммы SHA-256 опубликованы рядом с установщиками.
